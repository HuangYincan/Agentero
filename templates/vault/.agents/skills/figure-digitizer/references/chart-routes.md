# 路线手册：参数、质量门与拒绝条件

四条路线的共同骨架：

```
颜色掩膜（series.color ± tolerance，落在 plot_bounds 内，扣掉 exclude_regions）
        ↓
几何分组（列分组 / 逐列描迹 / 连通域）
        ↓
标定换算（像素 → 数值，含 log10 等变换）
        ↓
质量门（残差、歧义、缺口）→ 授权或降级
```

**路线来自图的语法，不来自你希望得到什么数。** 不要因为某条路线"能跑"就把不适格的图塞进去。

## 通用质量门

- 每轴至少两个已核对锚点；残差超过 `residual_limit × 轴跨度` 即阻塞授权。
- `exclude_regions` 只用于**看得见、说得清**的干扰源（图例、插画、水印、旁边面板的残影），并会在覆盖图与报告中留痕。**不得**用它删掉"不方便的"数据图元。
- 任何被拒绝的组件都要留在覆盖图上（橙色叉），而不是悄悄丢弃。
- 覆盖图与报告不一致时以覆盖图为准；那一次运行记为失败证据。

## line（折线 / 时间序列 / 曲线）

- 适用：颜色可分离的连续折线或标记连线，线性或对数轴。
- 关键参数：`plot_bounds`、两侧标定、`series[].color/tolerance`、`max_step_px`（限定相邻列的纵向跳变，压住网格线与相邻序列的干扰）。
- 几何：逐列取该列掩膜行的中位数作为该 x 处的 y；列内没有像素即为**缺口**，写进 `gap_ranges`，绝不插值。
- 已知边界：图例/注释与数据同色、多序列交叉处、被标记字形盖住的实线段 —— 这些位置要么被 `max_step_px` + 覆盖图确认，要么标 `low_confidence`。
- 它产出的是**可见笔画的轨迹**，不是作者的原始采样点；重拟合出来的曲线要标 `refit`，不能冒充原拟合。

## histogram（直方图 / 分布）

- 适用：颜色一致、落在同一基线上、彼此有可分辨间隙的柱子。
- 几何：列方向按掩膜高度分组，`max_gap_px` 合并抗锯齿造成的一两像素断口，`min_height_px` 滤掉坐标轴与网格残渣。
- 输出：每个 bin 的**可见柱高**与像素区间。柱高不是原始观测计数，bin 边界也受像素量化影响。
- 拒绝：柱子相互粘连且无间隙、半透明柱体重叠、基线不可见（无法确定柱底）。

## bar（柱状 / 分组 / 堆叠）

- 适用：颜色可分离的竖直柱，基线可见。
- 必填 `options.baseline_value`：值轴上的基线读数。脚本用标定把它换算成基线像素，并据此报告 `baseline_pixel`。
- 单元状态：基线像素落进柱体内部时，该柱标 `occluded_by_overlay` —— 数值仍从柱顶读出，但基线锚点被覆盖这件事必须留在证据里。
- 百分百堆叠：**保留每段的可见跨度，不做归一化**。段间隙与顶端缺口必须能用像素解释；解释不了就标 `low_confidence`。
- 拒绝：图例色块与数据同色且无法用可举证的排除区分开、被完全遮挡的段、3D/透视柱体。

## scatter（散点）

- 适用：紧凑实心标记，线性或对数轴。
- 几何：8 连通域 + 尺寸筛选（`min_component_px` / `max_component_px`），质心作为标记中心。
- 尺寸筛选是**歧义筛子**：过小的组件多半是网格线/坐标轴残渣，过大的组件多半是多个标记粘连。两者都进拒绝列表并推高 `unresolved_conflicts`，从而阻塞授权 —— **粘连的标记绝不被拆成多个点**。
- 已知边界：空心标记、渐变填充、气泡图（第三变量编码在大小上）、被柱体或曲线压住的点，均不在本路线范围内。
- 拒绝：密集到无法分离的点云、被遮挡的点、图例标记混入绘图区。

## 排除区写法

```jsonc
"options": { "exclude_regions": [[12, 40, 96, 110]] }   // [left, top, right, bottom]，原始像素
```

写之前问自己：这块区域在图上是**什么**？如果答不上来（"挡住结果的那块"），就不该排除。

## 晋升门槛（candidate → stable）

一条路线要脱离 `candidate`，需要补齐全部证据，缺一不可：

1. **合成样本**：已知真值的图，干净 PNG / 低分辨率 JPEG / 深色主题各一份，误差在预设容差内；
2. **真实样本**：来自公开出版物、类型分散的留出集，逐例给出覆盖图与诊断；
3. **拒绝样本**：已知该拒绝的图（遮挡、粘连、无法标定），必须被正确拒绝而不是给出数字；
4. **外部对照**：与独立的图形数字化工具在同一张图上做公平对比（同一图、同一目标量、公开参数）；
5. **可复现**：上述所有案例能被仓库内的脚本或数据重建。

在此之前：允许用，必须在交付里写明是候选级证据。
