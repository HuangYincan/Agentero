# 官方源数据独立校验

论文提供了 XLSX / CSV / 补充数据 / 数据仓库时，它是**校验基准**，不是抽取结果的改写来源。

## 铁律

1. **先冻结**：`data.csv` 一经写出即冻结。任何源数据比对都写进**新文件**，绝不回写抽取表。
2. **先证映射，再比数字**：只有在面板 → 指标 → 单位 → 统计量 → 源数据列的映射被逐条确认之后，源数据才算 ground truth。**同名不等于同一指标**。
3. **比汇总，不比重复测量**：图上画的是均值/中位数/汇总值时，就拿它和源数据的对应汇总比；点级吻合只能证明"画出来的点被正确读出"，不能证明作者的拟合方法或未公开参数。
4. **单位不许悄悄换算**：源数据与坐标轴单位不一致时，把换算因子和依据留在校验文件里，而不是把源数据缩放成"看起来一致"。

## 校验文件

在同一个产物目录下另建：

```
{paper}/source/digitize/<figure-id>/
├── data.csv                     # 冻结，不动
├── source-validation.csv        # 逐点/逐组的配对比对
└── source-validation.json       # 映射声明 + 覆盖率 + 状态统计
```

`source-validation.json` 至少声明：每个面板映射到哪个源数据工作表/列、响应指标与单位、浓度或时间的变换、图上显示的是哪个统计量、以及每个配对的状态：

| 状态 | 含义 |
|---|---|
| `validated` | 图上值与源数据在声明容差内一致 |
| `partial_validated` | 部分配对通过，缺口或单位问题已记录 |
| `metric_absent_in_source_workbook` | 源数据里没有对应指标 |
| `source_unit_unresolved` | 单位无法确定，未做换算 |
| `not_comparable` | 两者不可比（定义不同、汇总口径不同等） |

## 结论怎么写

- 源数据**覆盖不到**的位置不是抽取失败，分开报告；
- 源数据与图上值冲突时，先怀疑映射声明，再怀疑抽取；两者都复核对不上，就如实写"冲突"，不要二选一；
- 任何"用源数据修正后的曲线"都必须标为派生结果，并保留原始抽取表在旁边。
